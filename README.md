沖縄本島・宮古島・石垣島（2026年10月17日〜24日）の新婚旅行しおり。GitHub Pagesで公開している静的HTML1枚のページです。

## 公開URL

https://alfortx.github.io/okinawa-trip-2026/

## 内容

- Day1〜8の行程（フライト便名、観光スポット、宿泊先を予約確定情報ベースで記載。予約番号は非公開）
- 目次から各Dayへジャンプ可能

## 表示について

- スマホ幅（〜899px）：1カラムのカード型レイアウト
- PC幅（900px以上）：左に目次を固定した2カラムレイアウト
- レイアウト切替はCSSのみ（`@media (min-width: 900px)`）で自動判定。JS不要。

## 更新方法

`index.html` を直接編集して `main` ブランチにpushすると、GitHub Pagesへ自動反映されます。
